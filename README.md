# Dead Village

First-person stealth zombie survival for Android browsers. Aim by moving your phone (gyroscope), walk with the on-screen stick, hide in tall grass, throw stones to distract, and reach the bell tower.

Play it: https://YOUR-USERNAME.github.io/dead-village/

To install on Android, open the link in Chrome, tap the ⋮ menu, then "Install app" (or "Add to Home screen").
